# Meeting Management System

## Description

A Meeting Management System designed to help secretaries efficiently submit, schedule, and manage meetings for their managers. The system allows managers to review, edit, or cancel meetings in an easy and organized manner. It also provides a clear distinction between upcoming and completed meetings, ensuring streamlined meeting management.

![image](https://github.com/user-attachments/assets/bdcc8596-550f-440c-948c-15b641cab23e)


## Features

- **Submit Meetings**: Secretaries can submit new meeting schedules with detailed information.
- **Review & Edit**: Managers can review submitted meetings, make edits, or cancel them if necessary.
- **Organized Views**:
  - **Upcoming Meetings**: View all scheduled future meetings on a dedicated page.
  - **Completed Meetings**: Access a list of all completed meetings on a separate page.
- **Status Tracking**: Meetings can have one of four statuses: Not Started, Ready, Completed, or Canceled.

## Tech Stack

- **Backend**: Node.js/Express with Sequelize ORM
- **Database**: MySQL
- **Frontend**: React - zustand
